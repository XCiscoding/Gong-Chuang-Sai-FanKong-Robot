# ZiMing｜Motor

这个分支只保存子明负责的 X42S 电机、底盘运动与停车安全链源码；不包含视觉模型、机械臂代码、IDE 构建输出或实物试验缓存。

## 当前模块

- `firmware/f407-open-loop-first-route/`：STM32F407 开环底盘路线候选。目录内 README 记录构建、烧录和实物证据边界；源码归档不代表整条路线已通过。

## 仓库分支约定

- `YuXuan/Vision`：视觉模块。
- `ZiMing/Motor`：电机与底盘模块（当前分支）。
- `ZiMing/Arm`：机械臂模块，获得独立可复现源码后再建立。
- `main`：仅用于已经完成跨模块验证的集成版本；不会把开发中模块直接混入。
